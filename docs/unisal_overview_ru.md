# Обзор пайплайна UNISAL

## Входные данные и подготовка
UNISAL принимает на вход последовательности кадров в формате тензора `B x T x C x H x W`, где `B` — размер батча, `T` — количество кадров, `C` — каналы цвета (RGB), а `H` и `W` — высота и ширина после приведения к размеру модели. Наши скрипты извлекают кадры из видео с помощью OpenCV, переводят их в RGB и нормализуют по статистикам ImageNet, чтобы привести к ожиданиям модели.【F:generate_unisal_saliency.py†L82-L135】【F:generate_unisal_overlay_video.py†L154-L169】

## Инференс и генерация карт внимания
Для видео мы активируем видеопуть модели (`static=False`), чтобы UNISAL учитывала временную динамику при расчёте внимательности. Модель возвращает карту вероятностей для каждого кадра, которую мы преобразуем в двумерное распределение внимания и используем при построении тепловых карт.【F:generate_unisal_saliency.py†L137-L276】【F:generate_unisal_overlay_video.py†L236-L258】

## Скрипт `generate_unisal_overlay_video.py`
Скрипт формирует задания для каждого видео, при необходимости распараллеливает их и для каждого кадра строит тепловую карту. Кадры накладываются поверх оригинального изображения и сохраняются в промежуточный видеофайл без аудио. После завершения инференса оригинальная звуковая дорожка встраивается обратно в итоговый ролик. По умолчанию скрипт работает в одном процессе, но можно указать больше воркеров для ускорения.【F:generate_unisal_overlay_video.py†L44-L196】【F:generate_unisal_overlay_video.py†L289-L434】

## Скрипт `generate_unisal_saliency.py`
Этот инструмент предназначен для анализа первых секунд ролика и создания набора тепловых карт и числовых метрик (например, силы хука). Он переиспользует те же функции подготовки данных и инференса, но вместо финального видео сохраняет изображения и агрегированные статистики по кадрам.【F:generate_unisal_saliency.py†L42-L205】【F:generate_unisal_saliency.py†L256-L324】
