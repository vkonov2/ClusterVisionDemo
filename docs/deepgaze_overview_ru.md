# Обзор пайплайна DeepGaze IIe и DeepGaze III

## Основные отличия моделей

| Модель | Назначение | Ключевые особенности |
| --- | --- | --- |
| **DeepGaze IIe** | Классическое предсказание статических карт внимания. | Сводит несколько предобученных бэкбонов в ансамбль, возвращает лог-плотность вероятности фиксации для каждого пикселя. Не использует историю взора. |
| **DeepGaze III** | Прогнозирование следующей фиксации с учётом траектории взгляда. | Помимо карты внимания учитывает предыдущие точки фиксации (scanpath) через обучаемый модуль памяти. Возвращает лог-плотность для следующего шага и позволяет моделировать путь взгляда. |

DeepGaze III по сути расширяет DeepGaze IIe: карта внимания зависит не только от текущего кадра, но и от истории фиксаций. Поэтому модель подходит не только для визуализации вероятных областей интереса, но и для построения вероятных «маршрутов» взгляда.

## Что делает скрипт `generate_deepgaze_saliency.py`

1. **Загрузка модели и центр-биаса.** Репозиторий DeepGaze клонируется в кеш, скачивается log-density центр-биаса MIT1003 (либо используется равномерный фон).
2. **Чтение кадров.** Видео разбирается на кадры (по умолчанию первые 5 секунд, без пропуска кадров).
3. **Предобработка.** Каждый кадр конвертируется в RGB-тензор без дополнительного масштабирования — модели DeepGaze сами приводят размер к нужному виду.
4. **Инференс.**
   - Для DeepGaze IIe кадры собираются в батчи, модель сразу выдаёт лог-плотности.
   - Для DeepGaze III поддерживается очередь последних фиксаций (по умолчанию заполняется центром кадра и дальше обновляется по максимумам вероятности).
5. **Постобработка.** Лог-плотности переводятся в вероятностные карты, сохраняются тепловые карты, оверлеи и агрегаты (mean/max) для первых кадров.

## Что делает скрипт `generate_deepgaze_overlay_video.py`

1. **Батчевый запуск.** Можно обработать одно видео или целую директорию (с прогресс-барами для каждого файла). По умолчанию обработка идёт последовательно, но параметр `--workers` позволяет параллелить.
2. **Инференс и запись.** Для каждого кадра строится карта внимания, поверх оригинального кадра формируется тепловая маска, кадры кодируются в временное MP4 без звука.
3. **Возврат аудио.** После инференса исходная звуковая дорожка подмешивается обратно через `ffmpeg`, при желании временное видео удаляется.
4. **Настройка центр-биаса.** Можно использовать шаблон MIT1003, свой файл или равномерный фон.
5. **Особенности DeepGaze III.** Если выбрана эта модель, очередь фиксаций передаётся в каждый кадр, что позволяет учитывать историю взгляда при построении новой карты.

## Как использовать

### Пример одиночного запуска

```bash
python generate_deepgaze_overlay_video.py \
  --video data/videos/000-youtube.mp4 \
  --output-video outputs/deepgaze/000-youtube/deepgaze2e_overlay.mp4 \
  --intermediate-video outputs/deepgaze/000-youtube/deepgaze2e_overlay_silent.mp4 \
  --model deepgaze2e
```

### Пример пакетной обработки с DeepGaze III

```bash
python generate_deepgaze_overlay_video.py \
  --input-dir data/videos \
  --model deepgaze3 \
  --workers 2 \
  --seconds 10
```

Второй пример рассчитан на то, что центр-биас MIT1003 уже скачан в кеш автоматически при первом запуске.

## Выводы

- DeepGaze IIe удобно использовать, когда нужна качественная статическая карта внимания без дополнительных данных.
- DeepGaze III подходит, когда важно учитывать путь взгляда и моделировать последовательность фиксаций.
- Оба скрипта автоматически подготавливают окружение, контролируют прогресс и сохраняют готовое видео с тепловой картой.
